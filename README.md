# CoreMVC "IS"
CoreMVC is an ASP.NET Core MVC project I use to learn the framework.
It is a place to experiment with augmenting architecture and attempting to implement patterns I come across.
The main goals are to build good Git habits, write lightweight requirements, and practice unit and integration testing.

# CoreMVC "IS NOT"
Not a production system, just a place to learn enterprise patterns.
